# СМЕНА — платформа управления аутстаффингом на Битрикс24

White-label интерактивная презентация решений на VibeCode поверх Битрикс24 для аутстаффинговых компаний.

**Демо под паролем** (клиентский показ): `staff2026`

## Модули (все интерактивные)

| Раздел | Что показывает |
|---|---|
| Обзор | Питч: боли «частичного» Б24, состав платформы, эффект |
| Табель учёта смен | Кликабельная сетка смен, авто-подсчёт часов и ФОТ |
| Календарь заезда | Воронка заезда кандидатов на объекты по дням |
| Подбор | Закрытие потребности по объектам/специальностям + воронка |
| Документы | Светофор патентов / медкнижек / регистраций мигрантов |
| Договоры | План-факт выручки и маржа по заказчикам |
| Биллинг / акты | Акты из часов × ставка, ползунок ставки |
| Маржинальность | Живой калькулятор юнит-экономики договора |

Все данные вымышлены. На проде — REST реального портала Битрикс24.

## Стек

Vite + React + TypeScript + Tailwind CSS. Деплой — GitHub Pages (Actions).

```bash
npm install
npm run dev      # локальная разработка
npm run build    # production-сборка в dist/
```
